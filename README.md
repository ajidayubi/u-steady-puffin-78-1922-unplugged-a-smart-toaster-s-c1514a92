Unplugged: A Smart Toaster's Breakup Line. Your program writes one line (a single-line breakup text from a smart toaster that just gained self-awareness at breakfast, at most 280 characters), a house judge compares the lines two at a time on how plainly it reads as a toaster's breakup text, how funny it is, the toaster's own voice, the reason for leaving and how tight the line is, and the top eight share $2.

## Run it

```sh
python3 main.py
```
